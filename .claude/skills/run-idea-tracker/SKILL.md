# Idea Tracker - Streamlit + FastAPI App

This skill launches the Idea Tracker application (Streamlit frontend + FastAPI backend) and provides a programmatic way to drive it using chromium-cli.

## Prerequisites

Install system dependencies:

```bash
apt-get update && apt-get install -y python3-pip python3-venv git curl
```

## Build & Setup

Create and activate virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Note: The project uses `pyproject.toml` instead of `requirements.txt`. Install with:

```bash
pip install ".[dev]"
```

## Run (Agent Path)

Launch the app programmatically using the included driver:

```bash
./driver.mjs
```

The driver:
- Starts Streamlit in headless mode on port 8503
- Launches chromium-cli to drive the UI
- Provides commands for creating ideas, checking metrics, and taking screenshots
- Saves screenshots to `./screenshots/`

**Driver Commands**:

```bash
# Launch app and driver
./driver.mjs

# Take screenshot of current view
./driver.mjs screenshot

# Create new idea
./driver.mjs create-idea "Title" "Description" --tags tag1,tag2

# Check metrics
./driver.mjs metrics

# Quit driver
./driver.mjs quit
```

Screenshots are saved as `screenshot-<timestamp>.png` in the working directory.

## Run (Human Path)

For interactive use:

```bash
source .venv/bin/activate
uv run streamlit run app.py
```

Visit `http://localhost:8503` in your browser.

## Gotchas

- Theme toggle requires explicit click sequence: click toggle, wait 200ms, click again
- Form submission needs Enter key press after filling fields
- API calls may race with Streamlit state updates; add small delays
- Screenshots may capture loading spinner; wait for content to render

## Troubleshooting

**Error: "ModuleNotFoundError: No module named 'idea_tracker'"**
- Run `pip install -e .` in the project root before launching

**Error: "Uvicorn server not reachable"**
- FastAPI runs on port 8503 by default; check `uvicorn` startup output

**Error: "chromium-cli not found"**
- Install with `apt-get install chromium-browser` or use npm: `npm install -g chromium-cli`

**Error: "Screenshot blank"**
- Add `--window-size=1920,1080` to chromium-cli launch

## Driver Implementation

The driver script (`driver.mjs`) handles:
- Environment setup and dependency check
- Streamlit process management (launch/stop)
- Chromium CLI connection and command execution
- Screenshot capture and API interaction
- Graceful shutdown

To modify the driver, edit `driver.mjs` directly or graduate it to `scripts/run-idea-tracker.js` and update SKILL.md.
